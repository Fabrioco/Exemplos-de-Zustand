# Criei esse repositório para treinar com o zustand de forma simples

## Iniciando o projeto

```bash
git clone https://github.com/Fabrioco/Exemplos-de-Zustand
# Depois entre na pasta do projeto
cd exemplos-de-zustand
# Instale as dependerias
npm install
# Rode o projeto
npm run dev
```

### 🧠 O que é o Zustand?
Zustand é uma ferramenta para guardar e controlar dados que várias partes do seu aplicativo precisam usar — tudo isso de forma simples e rápida.

**📦 Imagine assim:**
Você tem vários componentes no seu app (como páginas, botões, listas etc). Às vezes, esses componentes precisam compartilhar informações entre si, por exemplo:

O número de itens no carrinho de compras 🛒

O usuário que está logado 👤

Um tema escuro ou claro 🌙☀️

**🔄 Sem o Zustand:**
Você teria que passar essas informações de componente em componente, o que vira uma bagunça.

**✅ Com o Zustand:**
Você cria uma "caixinha" de estado (store), onde coloca esses dados. Depois, qualquer componente do app pode pegar ou alterar essas informações facilmente.

**🗣️ Um resumo bem direto:**
Zustand serve para compartilhar e controlar dados entre os componentes do seu aplicativo sem complicação.
